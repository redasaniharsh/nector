# Néctar - Luxury Fruit Confection

A stunning, highly interactive 3D landing page for "Néctar" luxury fruit confections. Built with React, Three.js (React Three Fiber), and Tailwind CSS. The site features a beautifully rendered 3D glass jar filled with vivid fruit gummies, complete with dynamic lighting, scroll-linked animations, and a premium aesthetic.

## Features

- **Interactive 3D Hero**: Real-time 3D rendered apothecary glass jar with dynamic lighting and floating fruit gummies.
- **Scroll Choreography**: Cinematic text reveals and camera movements tightly linked to scroll progress.
- **Premium Design**: Dark mode aesthetic, warm amber lighting, glassmorphism UI elements, and careful typography.
- **Fully Responsive**: Optimized layout that gracefully adapts from mobile screens to desktop viewports.
- **Frame Sequence Engine**: Custom WebGL rendering engine to control 3D animation frames.

## Tech Stack

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Three.js](https://threejs.org/) / [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide Icons](https://lucide.dev/)

## Running Locally

**Prerequisites:** Node.js (v18+)

1. Clone the repository:
   ```bash
   git clone https://github.com/chandan22468/nector.git
   cd nector
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   bun install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser to `http://localhost:5173`
